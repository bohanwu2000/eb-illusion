# The Illusion of Learning from Observational Data: An Empirical Bayes Perspective

>The Illusion of Learning from Observational Data: An Empirical Bayes Perspective

>Bohan Wu, Sebastian Salazar, Donald P. Green, David M. Blei, 2026

## Code

- [`src/calibrated_EB_simulation.ipynb`](src/calibrated_EB_simulation.ipynb) — simulation study
- [`src/water-analysis.ipynb`](src/water-analysis.ipynb) — semi-synthetic real data analysis based on the water usage data
